개인정보처리방침

포츈쿠키 (Fortune Cookie) · 최종 업데이트: 2026년 6월 12일

1. 수집하는 정보

포츈쿠키 앱은 어떠한 개인정보도 수집하지 않습니다. 앱은 외부 서버와 통신하지 않으며, 사용자 계정 생성이나 로그인 기능이 없습니다.

2. 기기 내 저장 데이터

다음 정보는 사용자의 기기에만 저장되며 외부로 전송되지 않습니다.

  • 오늘의 포츈쿠키 사용 횟수 및 초기화 시각
  • 오늘 이미 표시된 운세 메시지 목록 (중복 방지용)
  • 잠금화면·홈화면 위젯 상태

이 데이터는 앱을 삭제하면 함께 삭제됩니다.

3. App Groups (앱·위젯 간 데이터 공유)

메인 앱과 위젯이 남은 횟수를 실시간으로 공유하기 위해 iOS App Groups(group.com.fortunecookie.shared)를 사용합니다. 이 데이터는 사용자의 기기 내에서만 공유되며 외부로 전송되지 않습니다.

4. 제3자 서비스

포츈쿠키는 광고 SDK, 분석 도구, 트래킹 라이브러리를 포함하지 않습니다. 어떠한 제3자 서비스에도 데이터를 전송하지 않습니다.

5. 공유 기능

운세 결과를 공유할 때 iOS 기본 공유 시트를 사용합니다. 앱은 어떤 공유 대상을 선택했는지 기록하거나 저장하지 않습니다. 공유 이미지는 사용자가 직접 선택한 앱(카카오톡, 메시지 등)으로 전달되며, 이 과정은 앱의 관여 없이 iOS가 처리합니다.

6. 아동 개인정보 보호

이 앱은 만 4세 이상을 대상으로 하며, 13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 수집되는 개인정보 자체가 없으므로 해당 사항이 없습니다.

7. 방침 변경

개인정보처리방침이 변경될 경우 이 페이지를 통해 공지합니다. 앱을 계속 사용하시면 변경된 방침에 동의하는 것으로 간주합니다.
